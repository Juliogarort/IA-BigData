# Sistema Experto: Análisis de Incidentes


## Requisitos
- Python 3.x instalado.
- Archivos `sistema_experto.py` e `incidentes.csv` en la misma carpeta.

## Cómo ejecutar el programa

### Opción A: Desde VS Code (Recomendado)
1. Abre la carpeta del proyecto en **Visual Studio Code**.
2. Asegúrate de tener instalada la extensión oficial de **Python** (de Microsoft).
3. Abre el archivo `sistema_experto.py`.
4. Haz clic en el **botón de "Play" (Run Python File)** que aparece en la esquina superior derecha del editor, o haz clic derecho en el código y selecciona **"Run Python File in Terminal"**.

### Opción B: Desde la Terminal (Cualquier SO)
1. Abre tu terminal y navega hasta la carpeta del proyecto.
2. Ejecuta el siguiente comando:
   - En **Windows**: `python sistema_experto.py`
   - En **macOS / Linux**: `python3 sistema_experto.py`

## Resultados
Al finalizar la ejecución, el programa generará automáticamente un archivo llamado **`informe_incidentes.txt`** en la misma carpeta. Este archivo contiene el análisis completo de todos los incidentes procesados.
